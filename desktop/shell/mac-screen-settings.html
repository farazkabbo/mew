Neb on your Mac

Open your notebook with Control + Shift + N. Use Neb tools to draw local notes over your screen. Toggle Neb tools with Control + Shift + I. Hold Control + Shift + Space to ask about your screen, then release to send. If that shortcut is unavailable, use the microphone on Neb tools.

Neb tools

Local preferences

Drawings stay in memory until you clear or close them. Mac annotations may appear in screen recordings and screen shares. Enable this only if that is okay with you. This does not by itself allow screen capture.

When you ask with Neb's microphone, Circle & Ask, or enable Watch, Neb captures the focused supported document window. It checks blocked apps, password fields and known calls; an indicator appears before capture. It redacts text locally before sending an image to your signed-in Neb server. Watch checks changed content every six seconds for up to 45 minutes. Detection cannot identify every screen share. Unknown/private browser windows are refused. Screenshots stay in memory until used, cancelled or expired. Only saving a clip stores the selected image in your notebook. You can pause or disable Screen Coach at any time.

In macOS System Settings → Privacy & Security, enable Screen & System Audio Recording and Accessibility for Neb. Microphone permission is requested when you first use voice.

Blocked apps are never read. Mac bundle identifiers such as com.apple.Mail work here; existing Windows app names are kept for compatibility. Password managers and protected fields remain refused.

Automatic saving creates an explanation in your notebook after a five-second Undo period. The selected save preference applies to every Circle & Ask explanation.

Payment cards, passwords, secret keys and verification codes are always covered on Mac. If a safety check is unavailable, screen capture is refused.

Neb checks each proposed action, avoids sensitive controls and stops when you press Escape. You remain responsible for confirming payments, sending, deleting and other sensitive actions yourself.

CATCH ME reads the names of nearby controls on this Mac, and—in unblocked supported apps—email draft words, attachment and recipient counts, unsaved changes, selected files and the terminal line being typed. It warns about reply-all, missing attachments, losing unsaved work, deleting files and risky terminal commands. Those facts stay on this computer and are not sent to the planner. Blocked apps and protected fields remain unread. You can turn it off here or pause Screen Coach.

CATCH ME rules

Handoff keeps up to 24 hours of app context and saved moments in an encrypted local timeline, isolated to this account. A draft shows the selected moments and redacted text before anything is shared. Only Send uploads an encrypted package. Turning the timeline off deletes its local records. Picking up someone else's work asks before each file, page or repository action; commands are copied for you to review.

Cursor developer tools

The debug view shows predicted cursor positions. Trace recording saves positions, timing and control rectangles locally, without names or screen contents. Up to 200 recent traces are kept for this account.

Screen Coach availability

Use the microphone on Neb tools to start a question; press it again to finish. Press Escape to cancel. Select the Watch control for periodic help. Neb can guide and act in supported apps after you enable the relevant preferences.
